Datadog RUM to Redshift pipeline

User-session data from Datadog sat in a silo with no schema governance. I built a serverless pipeline that pulls it, stages it as Parquet, and upserts it into Redshift without duplicates, even when pulls overlap.

How it works
  • Replaced heavy SDKs with direct, paginated HTTPS calls, keeping the Lambda package well under its 250MB limit.
  • PL/pgSQL stored procedures (COPY + MERGE) upsert overlapping 30-day windows on natural keys.
  • A fixed-column allowlist absorbs upstream schema drift; Redshift Data API polling and timing logs make every run observable.
